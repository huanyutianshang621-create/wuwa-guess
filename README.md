# 鸣潮立绘猜猜看

给完全没玩过鸣潮的朋友玩的猜角色小游戏：看立绘，选属性，再选名字。
不需要联网、不需要安装、不需要构建，双击 `index.html` 就能玩。

---

## 1. 怎么玩

1. 双击 `index.html`（推荐 Chrome / Edge）。
2. 开始页有两个选择：「开始猜」进对局，「看图鉴」只浏览 57 张立绘（没有名字、属性、简介，点开也只有大图）。
3. 看立绘 → 在「她的属性是」里选一个（冷凝 / 热熔 / 导电 / 气动 / 衍射 / 湮灭）。
4. 选完立刻判对错，然后「她叫什么」里的四个名字才亮起来。
5. 选完名字 → 显示答案：名字、属性、星级、武器、版本。
6. 点「下一张」继续。

**没有「一局」的概念**：57 张随机排队，答一张记一张，进度自动存进浏览器。
想走就走，下次打开还是接着那一张往下猜，直到 57 张全部认完。

全部答完后会给出本轮统计，并且可以「复习答错的 N 张」。

顶栏的「图鉴」会列出全部 57 张：认出过的显示立绘和名字，没认出的只剩灰色剪影和「？？？」。
**认出过的角色可以点开**：大图 + 星级、武器、版本 + 一句角色简介，点空白处或按 `Esc` 关闭。

开始页的「看图鉴」是**预览模式**：57 张立绘全部可见，但没有名字、属性、简介，点开也只有一张大图，关掉回到开始页。

### 键盘

| 键 | 作用 |
| --- | --- |
| `1`–`6` | 选属性（顺序同界面） |
| `1`–`4` | 属性选完后，选名字 |
| `Enter` / 空格 | 开始页：开始猜；对局中：下一张 |
| `Esc` | 关闭图鉴 / 关闭大图 |

计分：属性 +10，名字 +20，两个都对再 +10（满分 40/张）。
想改成别的分数，见下面第 4 节。

## 2. 目录结构

```
wuwa-guess/
├─ index.html          页面骨架（四段：开始页、对局、结束页、图鉴）
├─ css/style.css       全部样式，配色在文件开头的 :root 里
├─ js/
│  ├─ config.js        可调参数：选项数、计分、图片目录、六属性颜色和提示词
│  ├─ data.js          角色名单：一个角色一行
│  ├─ bios.js          角色简介：键是 data.js 里的 id，图鉴大图里显示
│  └─ game.js          流程逻辑（出题、判分、存档、渲染）
├─ images/             立绘放这里（文件名要和 data.js 里的 img 对上）
├─ 复制图片.bat        把桌面那个文件夹里的 57 张 webp 拷进 images/
└─ README.md
```

---

## 3. 立绘放哪

`images/` 里已经放好了 57 张立绘，**工程是自包含的**：整个文件夹拷到任何电脑、或者直接传到网页托管，双击 `index.html` 就能玩。

如果以后要换一批图（比如加了新角色）：

- **方法一**：双击 `复制图片.bat`，它会在桌面（含 OneDrive 桌面）里找带 `T_ActivityRole*.webp` 的文件夹，把图片拷进 `images/`。
- **方法二**：手动把 `.webp` 拖进 `images/`。

图片文件名必须和 `js/data.js` 里的 `img` 字段一致。`js/config.js` 的 `IMG_DIRS` 现在只有 `"images/"` 一项，够用了。

## 4. 怎么改（这部分就是「随时能改源文件」的答案）

### 加一个角色

打开 `js/data.js`，照抄一行改掉内容：

```js
{ id: "xinjuese", name: "新角色", element: "fusion", star: 5, weapon: "迅刀", version: "3.9", img: "T_ActivityRoleXinjuese.webp" },
```

- `id` 不能和已有的重复（存档、图鉴都靠它）；
- 把对应立绘丢进 `images/`；
- 刷新页面即可，**旧存档不会丢**：新角色会自动排到队尾。

### 删角色 / 改名

直接从 `data.js` 删掉一行即可。改 `id` 等于换了个新角色，旧进度会对不上，改 `name` 只影响显示。

### 改角色简介

`js/bios.js` 就是一张「id → 一句话」的表：

```js
window.WUWA_BIOS = {
  "yangyang": "今州的信使，骑着风声在城里送信……",
  ...
};
```

- 想换措辞直接改字符串；想让某个角色暂时没简介，把那一行删掉（大图里就不显示这一段）。
- 加了新角色记得也在这里补一条，键要用 `data.js` 里的 `id`。
- 现在这 57 条简介是照 wiki 公开设定写成的一句版，不是官方原文；给朋友科普够用，别当设定集引用。

### 改计分、选项数量、图片目录

`js/config.js`：

```js
OPTION_COUNT: 4,                                   // 名字给几个选项
SCORE: { element: 10, name: 20, both: 10 },        // 属性分 / 名字分 / 全对奖励
GALLERY_SHOW_LOCKED: false,                        // 图鉴里没猜出来的角色能否点开（true = 剧透）
```

### 改六属性的颜色和提示词

同一个文件里的 `ELEMENTS`。`hint` 是按钮上那行小字（"冰霜 · 寒气"），
给没玩过的人一点线索；觉得太剧透就把它改成空字符串 `""`。

### 改配色 / 文案

- 配色：`css/style.css` 开头的 `:root` 变量。
- 标题、按钮文字：`index.html`。

## 5. 数据说明

角色名与属性按 **鸣潮灰机wiki 的「Data:角色.tabx」数据表**整理，核对于 2026-11-19，
覆盖到 3.8 版本，共 57 名自机角色（四星也都在内）。属性分布：冷凝 9、热熔 11、导电 10、气动 10、衍射 9、湮灭 8。

「漂泊者」（主角，有衍射 / 湮灭 / 气动 / 导电四个属性形态）没有对应的立绘文件，所以没进题库。

## 6. 已知限制

- 纯静态页面，靠 `file://` 打开。Chrome / Edge 正常；个别浏览器会拦本地图片，换个浏览器即可。
- 进度存在浏览器 localStorage 里：换浏览器、清浏览器数据会丢。想给不同朋友各玩一份，可以用各自电脑上的浏览器打开。
- 没有计时、没有音效、没有成就（按需求砍掉了）。
- 立绘约 21 MB，全部是 2048×2032 的方形图，首屏首次加载会慢一两秒，之后走缓存。
